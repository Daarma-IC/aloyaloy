# NusaMesh releases

Versi terbaru: [v0.3.0 (16)](v0.3.0/).

- [APK Android release signed](v0.3.0/NusaMesh-v0.3.0-release.apk): untuk instalasi langsung.
- [Android App Bundle](v0.3.0/NusaMesh-v0.3.0-release.aab): untuk alur distribusi melalui store.
- [Source iOS](v0.3.0/NusaMesh-v0.3.0-ios-source.zip): source dan skrip untuk build di Mac, **bukan IPA**.

Manifest JSON memuat SHA-256 masing-masing artefak. Sertifikat dan hasil verifikasi signature Android disertakan. Keystore dan password tidak disertakan.

APK menggunakan release key baru, berbeda dari APK debug. Instalasi debug tidak dapat diperbarui langsung menggunakan APK ini; cadangkan data sebelum mengganti instalasi.

Panduan build/signing: [RELEASE.md](../apps/nusamesh/docs/RELEASE.md).
